# 在微信开发者工具里体验真产品（3 步）

> 现在的状态：`utils/config.js` 已设 `CLOUD:true`，后端已在 `http://127.0.0.1:8000` 运行（真 hy4）。
> 你只需要导入项目、关一个开关、编译。

## 第 1 步：导入项目

1. 打开你桌面上的**微信开发者工具**
2. 点「+」或「导入项目」
3. **目录**选：
   ```
   D:\12412\dsh工作区\projects\make-again-post-merge
   ```
   （这个目录下有 app.json / project.config.json）
4. AppID：选「**测试号**」（没有小程序 AppID 就选这个，能本地跑）
5. 点「确定」/「导入」

## 第 2 步：关掉域名校验（关键，否则连不上本地后端）

顶部菜单栏 → **详情** → **本地设置** → 勾选：
- ☑ **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**

（不勾这个，小程序会拒绝访问 `http://127.0.0.1:8000`）

## 第 3 步：编译、体验

点顶部「**编译**」按钮，模拟器里就会出现真界面：

1. 登录页 → 点「**微信登录**」（本地测试号会直接进）
2. 同意授权 → 主创的信 → 「开始聊天」
3. 建档 4 题（昵称 / 生活阶段 / 最在意的事 / 陪伴期待）
4. 自由聊天 → **AI 回复是真实 hy4 生成的**
5. 点「聊天」tab 看历史，「我的」看画像，「收藏」看卡片

试试输入："我养的猫昨天走了" —— AI 会真实接住你的情绪。

## 常见问题

| 现象 | 原因/解决 |
|---|---|
| **`["usingComponents"]["t-button"]: tdesign-miniprogram/button/button 路径下未找到组件`** | npm 依赖没构建。我已经在本机装了 `node_modules` 并手动生成了 `miniprogram_npm/tdesign-miniprogram/`（8个组件全验证存在）。**重新导入项目**应该就好了；如果还报，在开发者工具点「工具 → 构建 npm」让它自己生成一次 |
| 连不上后端 / 回复还是假话 | 第2步的"不校验合法域名"没勾 |
